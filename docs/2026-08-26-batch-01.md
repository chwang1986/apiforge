## 技术决策

- 选用 **FastAPI** 作为底层框架（异步、自动文档、类型友好）
- 采用 **`@forge.tool`** 装饰器模式，一行代码暴露工具 API
- 包管理使用 **uv**，代码规范使用 **ruff**
